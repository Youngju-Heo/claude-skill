# 코드 공통 규칙 (모든 언어)

<!-- paths 없음: 모든 세션에서 로드됨. 언어 공통 규칙만 여기에 둔다. -->

- 코드 내부의 로그, 에러 메시지, Exception 및 CLI출력 텍스트등 사용자 UI 이외는 영어로 작성하라.
- 사용자에게 노출되는 UI 문자열은 한국어로 작성하라.
- 커밋 메시지와 문서는 한국어로 작성하라.
- 네이밍은 기존 코드가 있으면 기존 코드를 따르고, 없으면 아래 언어별
  규칙(.claude/rules/{언어}.md)을 따르라. 언어별 규칙에도 없는 경우
  해당 언어 생태계의 표준 컨벤션을 따르라.
- 코드에서 생성하는 JSON의 키는 snake_case로 작성하라.
- 변경 작업으로 README.md나 PROJECT_OVERVIEW.md의 내용(구조, 규칙,
  사용법)이 실제와 달라지면 해당 문서를 같은 작업에서 함께 갱신하여
  항상 최신 상태를 유지하라.
- 파일명은 kebab-case로 작성하며, golang 에서 사용하는 \_test 같은 파일명 접미사등의 언어 특별 사양은 원래 취지데로 사용하라.
